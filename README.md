1.. Клонировать репозиторий: `git clone https://github.com/chipollina/Dart_Lab1.git `

 Что я изучила: 
 1. Коллекции: List, Map, Set; их отличие от Python аналогов. Научилась использовать forEach, map, where.
 2. Каждая переменная имеет явный тип
(int, double, String, bool), и компилятор проверяет типы до запуска.
3. Dart не даёт обратиться к null без явной проверки. Познакомилась с типами String?, операторами ?. и ??

Ответы на вопросы:
1) В Python тип переменной проверяется только при запуске, а в Dart заранее. Это удобно тем, что ошибки видно сразу, ещё до запуска программы.
2) String - обычная строка, а String? строка, которая может быть null(не иметь значения)
3) В Python это просто договорённость, которую компилятор не проверяет. А final в Dart  реальный запрет: при попытке изменить значение переменной, будет ошибка.Это защищает от случайных изменений и делает
код предсказуемым.
4) Позиционный параметр передаётся по порядку, а именованный по имени и порядок не важен. Пример: 
позиционный: describePet('Барсик', 3);
именованный: describePet(name: 'Барсик', age: 3);
